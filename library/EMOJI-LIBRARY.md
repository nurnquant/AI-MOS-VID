## Utility markers

**Approved by the user 2026-08-23. Use them whenever the caption needs them.**

Not brand symbols — functional signposts. They always mean the same thing and
always sit in the same place, so a returning reader learns where to look without
being told. Kept separate from the palette above on purpose: the palette carries
meaning, these carry navigation.

|     | means                   | goes                           |
| --- | ----------------------- | ------------------------------ |
| 🎁  | the free-trial offer    | second to last, above the link |
| 🔗  | the link itself         | last line before the signature |
| 👇  | the engagement question | directly before the ask        |

Use each **once per caption**. Repeating them is what turns a signpost back into
decoration.

Everything else in a caption comes from the palette above, chosen for meaning.
